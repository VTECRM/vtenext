# vtenext — Legacy Project

> [!IMPORTANT]
> **vtenext (PHP 7) is being retired.** The legacy source code will be removed from this repository. The successor is **vtezero**, the new AI-native platform based on **PHP 8**.

## Introducing vtezero

**vtezero** is the next generation of the vtenext ecosystem. Built on PHP 8, it brings an AI-native approach to enterprise workflows, with a focus on process-driven AI agent governance, orchestration, and human oversight.

### Technology transition

| Previous platform | Successor platform |
| --- | --- |
| **vtenext** | **vtezero** |
| PHP 7 | PHP 8 |
| Legacy platform | AI-native platform |

## New project location

For the new platform and future development, visit the **vtezero GitHub organization**:

**https://github.com/vtezero**

## About this repository

The PHP 7-based vtenext source files are being removed from this repository. This repository will remain as an informational page announcing the transition to vtezero; **it will no longer host the legacy application code**.

For new projects, please refer to **[vtezero](https://github.com/vtezero)**.
